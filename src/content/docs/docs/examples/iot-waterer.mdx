title: Multi-plant auto waterer
description: Per-plant moisture signals + pump pulses with a cooldown state machine, plus a tank-level sensor that pauses all watering when empty and uses `when` blocks for edge-triggered alerts on the empty / refilled / low-water transitions.
---

A real-shaped IoT controller: three potted plants with capacitive moisture sensors on an ADS1115 ADC, three pumps on GPIO relays, and a fourth ADC channel for a reservoir-level sensor. Each plant has its own state machine — ok → watering → cooldown → ok — and the tank coordinates all of them through `when` blocks that fire once on each empty/refilled transition rather than every tick.

This is the example that earns Para's reactive primitives — multiple sensors feeding multiple actuators with cross-cutting safety state (the tank). The same code as plain JS would be either a pile of `prevX` flag tracking or an over-eager event bus.

## src/main.pts

The full source. Three Parabun helpers do the heavy lifting:

- **`gpio.openDefaultChip()`** — opens RP1 on Pi 5 / falls through to gpiochip0 elsewhere; one line, no chip-discovery boilerplate.
- **`i2c.ads1115("/dev/i2c-1")`** — opens the bus, binds the address (0x48 default), exposes `read(channel)` that hides the config-register write/wait/read dance.
- **`signals.cooldown(fn, { key, coolingMs })`** — wraps the pump action so concurrent calls AND calls within `cooldownMs` of the previous run are silently dropped. Replaces the per-plant ok/watering/cooldown phase tracking entirely.

```pts
import gpio from "parabun:gpio";
import i2c from "parabun:i2c";
import signals from "@para/signals";

interface Plant {
  name: string;
  channel: number;       // ADS1115 input (0..2)
  pumpPin: number;       // BCM number on the RP1
  dryAt: number;         // moisture < this → water
  pumpMs: number;        // pump pulse duration
  cooldownMs: number;    // anti-drown gap between pulses
}

const PLANTS: Plant[] = [
  { name: "basil",     channel: 0, pumpPin: 17, dryAt: 0.35, pumpMs: 1500, cooldownMs: 60_000 },
  { name: "fern",      channel: 1, pumpPin: 27, dryAt: 0.40, pumpMs: 2000, cooldownMs: 90_000 },
  { name: "succulent", channel: 2, pumpPin: 22, dryAt: 0.18, pumpMs: 800,  cooldownMs: 120_000 },
];
const TANK_CHANNEL = 3;
const TANK_EMPTY_AT = 0.05;
const TANK_LOW_AT = 0.20;

// ─── hardware: ADC + GPIO ───────────────────────────────────────────

const ads = i2c.ads1115("/dev/i2c-1");                    // 0x48 default; ±4.096V PGA default
const chip = gpio.openDefaultChip();                       // RP1 on Pi 5, gpiochip0 elsewhere
const pumps = new Map(
  PLANTS.map(p => [p.pumpPin, chip.line(p.pumpPin, { mode: "out", initial: 0 })]),
);

// Capacitive moisture sensors are typically wet≈10000 / dry≈26000
// raw — calibrate yours and adjust.
async function readChannel(ch: number): Promise<number> {
  const raw = await ads.read(ch as 0 | 1 | 2 | 3);
  return Math.max(0, Math.min(1, (26000 - raw) / (26000 - 10000)));
}

const notify = (msg: string) => console.error(`[notify] ${msg}`);

// ─── tank: signal → derived → when (the reactive win) ───────────────

const tankRaw = signals.fromInterval(() => readChannel(TANK_CHANNEL), 1000);
derived tankLevel = tankRaw.signal.get() ?? 1.0;
derived tankEmpty = tankLevel < TANK_EMPTY_AT;
derived tankLow   = tankLevel < TANK_LOW_AT;

when tankEmpty     { notify("⚠️  tank EMPTY — pausing all watering"); }
when not tankEmpty { notify("✓  tank back above empty — resuming watering"); }
when tankLow       { notify(`⚠ tank low — ${(tankLevel * 100).toFixed(0)}% remaining`); }

// ─── per-plant pump driver, rate-limited per-plant by cooldown ──────

const water = signals.cooldown(
  async (p: Plant) => {
    console.log(`💧 ${p.name}: pump ON for ${p.pumpMs}ms`);
    pumps.get(p.pumpPin)!.write(1);
    await Bun.sleep(p.pumpMs);
    pumps.get(p.pumpPin)!.write(0);
    console.log(`✓  ${p.name}: pump OFF`);
  },
  { key: p => p.name, coolingMs: p => p.cooldownMs },
);

// ─── tick: read every plant, water the dry ones if conditions allow

const tick = signals.fromInterval(async () => {
  const empty = tankEmpty;
  const cells: string[] = [];
  for (const p of PLANTS) {
    const m = await readChannel(p.channel);
    let action = "";
    if (m < p.dryAt && !empty) {
      const fired = await water(p);
      action = fired ? " → water" : " → wait";  // wait = in cooldown
    } else if (m < p.dryAt && empty) {
      action = " → SKIP (tank empty)";
    }
    const tag = m < p.dryAt ? "dry " : "ok  ";
    cells.push(`${p.name.padEnd(10)} ${(m * 100).toFixed(0).padStart(3)}%  ${tag}${action}`);
  }
  return `[tank ${(tankLevel * 100).toFixed(0).padStart(3)}%] ${cells.join(" │ ")}`;
}, 1000);

effect {
  const row = tick.signal.get();
  if (row !== undefined) console.log(row);
}

console.log(`watering ${PLANTS.length} plants — Ctrl-C to stop\n`);
await new Promise(() => {});
```

The shipped demo wraps this with a `--simulate` flag and a `--demo-empty` switch for dev-box testing — see [`demos/iot-waterer.pts`](https://github.com/airgap/parabun/blob/main/demos/iot-waterer.pts) on GitHub.

## What's reactive and what isn't

- **`signal tankRaw`** — periodic ADC read at 1 Hz. The only mutable cell in the tank chain.
- **`derived tankLevel`** + **`derived tankEmpty`** — read-only computations. `tankEmpty` recomputes every time `tankLevel` changes; nothing else has to track it.
- **`when tankEmpty { ... }`** + **`when not tankEmpty { ... }`** — fire once per false→true and true→false transition. The empty notification doesn't repeat every second the tank stays empty; the refilled notification fires only on the actual refill. This is the edge-triggered shape that's clumsy without language support — the alternative is hand-tracking `wasEmpty` and `if (empty && !wasEmpty)`.
- **`signals.cooldown(runPump, { key, coolingMs })`** — wraps the pump action so concurrent calls AND calls within `cooldownMs` of the previous run are silently dropped. Returns `Promise<boolean>` — true if it fired, false if it was suppressed. The `key` partitions the cooldown per-plant; `coolingMs` can be a number or a function of the call arguments. Replaces the per-plant `Map<name, { phase, lastWateredAt }>` you'd otherwise hand-write.

## Hardware

```
I²C bus 1 → ADS1115 @ 0x48
  ch 0..2 → capacitive moisture sensors (one per plant)
  ch 3    → analog tank-level sensor
GPIO chip pinctrl-rp1 (RP1, on Pi 5)
  BCM 17 / 27 / 22 → relay drivers for the three pumps
```

The default capacitive-moisture calibration assumes dry≈26000 / wet≈10000 raw; dunk + dry your sensors and adjust to taste. Use `--i2c <bus>` to override the default I²C bus number if your ADS1115 lives on something other than `/dev/i2c-1`.

## Run it

On the Pi with hardware wired up:

```bash
parabun src/main.pjs
```

That's it — the script auto-discovers the RP1 GPIO chip and opens the ADS1115 on `/dev/i2c-1`. It logs a status row at 1 Hz and notifies on the tank transitions:

```
[tank  84%] basil 45% ok  │ fern 68% ok  │ succulent 15% rest
[notify] ⚠ tank low — 12% remaining
[notify] ⚠️  tank EMPTY — pausing all watering
[tank   3%] basil 74% ok  │ fern 40% dry → SKIP (tank empty) │ succulent 0% rest
[notify] ✓  tank back above empty — resuming watering
💧 fern: pump ON for 2000ms
```

### Without hardware

`--simulate` swaps the I²C reads for a deterministic oscillator + a slowly-draining tank, so the demo also runs on a dev box. Pair with `--demo-empty` to drive the simulated tank to zero in ~12s instead of ~100s — useful for actually seeing the `when` block edges fire:

```bash
parabun src/main.pjs --simulate --demo-empty --seconds 14
```
